## What is a “Server”?
- A server is a computer that processes requests from client computers.
- Login requests, creating personal profiles, uploading videos, displaying Reels...

## How much do I need to study to build and use a server?
- There’s a lot to learn.

## Server Hosting Services
- You can quickly and reliably set up a server by using server hosting services provided by major companies like Amazon, Google, and Microsoft
- (BaaS: Backend-as-a-Service)

## What is Firebase?
- A server hosting service provided by Google
- It offers a variety of features, so it’s worth checking out

## When is it best to use Firebase?
When you’re just developing a quick, test-level app

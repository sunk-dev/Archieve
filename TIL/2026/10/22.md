2. 'Switch' is not defined react/jsx-no-undef
- React Router v6 업데이트에 따른 문법 수정
-  \<Switch\> 대신 \<Routes\> 로 대체하여 해결

~~~javascript
If you are using React Router v6

In React Router v6, <Switch> has been completely replaced by <Routes>. If you updated your packages recently, you need to change your code structure like this:
1. Update your import:javascript
import { Routes, Route } from 'react-router-dom';
Use code with caution.
2. Update your JSX:
Replace <Switch> with <Routes>, and pass your component inside the element prop instead of component:jsx
<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/services" element={<Services />} />
</Routes>
Use code with caution.

~~~

~~~javascript
//<Switch> 대신 <Routes> 로 대체하여 해결
const AppRouter=()=>{
    const[isLoggedIn, setLoggedIn]=useState(true);

    return(
        <Router>
            <Routes>
                {isLoggedIn ? (
                    <Route exact path="/" element={<Home/>}/>
        
                ):(
                    <Route exact path="/" element={<Auth/>} />
                )    
                }
            </Routes>
        </Router>
    );
};
~~~
